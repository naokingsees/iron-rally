# IRON RALLY

武装カスタマイズ × バトルレースの3Dブラウザゲームです。車の武器や装甲をカスタマイズして、AIのライバル5台と撃ち合いながら3周のレースを走ります。

`index.html` と、Blender で作った車のモデル `assets/car.glb` で動きます（Three.js とフォントはCDNから読み込むため、インターネット接続が必要です）。`car.glb` を読み込めないとき（`index.html` を直接開いた場合など）は、簡易モデルで表示します。

## 遊び方

`index.html` をブラウザで開きます。直接開いて動かない場合は、ローカルのWebサーバー経由で開いてください。

| キー | 操作 |
| --- | --- |
| W A S D / 矢印キー | 運転 |
| Space | マシンガン |
| Shift | ホーミングミサイル |
| X | ドリフト（ハンドルと一緒に） |
| E | ニトロ |
| C | 視点切替 |
| R | コースに復帰 |
| P / Esc | ポーズ |

## 主な機能

- ガレージで車体・装甲・マシンガン・ミサイルポッド・エンジンを購入して付け替え（見た目にも反映）
- 夕暮れの峡谷サーキット（ヘアピン、S字、ジャンプ台、アイテム）
- ドリフトとドリフトブースト（3段階）、タイヤ痕とスモーク
- 撃破・ドリフトのボーナスつき賞金、進行状況は localStorage に保存
- グラフィック設定（低・中・高）

## 車のモデル（Blender）

`tools/build_car.py` は、Blender 上で車を組み立てて `assets/car.glb` を書き出すスクリプトです。

- ボディは断面をつないで面を作り、細分化（サブディビジョン）でなめらかにしています
- ホイールハウス、グリル、吸気口、ヘッドライト、テールランプ、ディフューザー、フェンダーの通気口、窓は、ブーリアンでくり抜いています
- ドア・ボンネット・トランクのパネル境界（6mmの溝）、方向性のあるトレッドパターンのタイヤ、装甲された車体下面とフレームもあります
- ヘッドライトのレンズは、ボディの面とぴったり揃うように作っています
- 光の回り込みで生まれる陰影（アンビエントオクルージョン）を Cycles で計算し、頂点カラーとして焼き付けています
- 遠くの車用に、ポリゴンを減らしたモデル（LOD）も一緒に書き出します

作り直すときは、`iron-rally` フォルダで次のコマンドを実行します（`--preview` を付けると確認用の画像も書き出します）。

```
blender -b --factory-startup -P tools/build_car.py -- assets --preview <画像の保存先フォルダ>
```

## 武装・ダメージ・AI

- 装甲は厚みのある角丸の板で、六角ボルト・継ぎ目（分割）・補強ステー・窓の保護バーが付きます。傷や角の塗装はげのテクスチャ入りです
- マシンガンは旋回リング・支持架台・装甲カバー・防盾付きです。撃つと反動で機関部が下がり、マズルフラッシュが光り、撃ち続けると銃身が赤熱します
- ミサイルポッドは発射管と開閉する前面カバー付きです。発射すると反動と後方への排気が出て、残弾は発射管の弾頭の数で見えます
- ミサイルは前方の敵を0.6秒捉えるとロックオンし、画面に照準枠を表示します
- 弾が当たった車体の表面に弾痕が残ります
- ダメージは段階的に表れます。塗装のつやが落ちてすすけ、45%以下でヘッドライトがちらついて消え、25%以下で部品が脱落して速度が落ちます
- ライバルは5つの戦術タイプです。攻撃型（BLAZE）は体当たりと長い連射、防御型（ONYX）は後ろの車をブロック、スピード型（VIPER）は早めの追い抜きとニトロ、妨害型（NOVA）はミサイルの多用と体当たり、バランス型（RAZOR）は状況に応じて動きます。撃たれると反撃したり、蛇行して避けたりします

## グラフィック

- 塗装はメタリックの微細なフレークとクリアコート。路面・砂利・砂地・岩は凹凸（ノーマルマップ）と光沢の差があります
- 高画質では画面空間のアンビエントオクルージョン（GTAO）で接触部分に陰影が付きます
- 色調補正と周辺減光、高速走行時の放射ブラー、被弾時の色ずれを最後に重ねます
- プレイヤー車のヘッドライト、マズルフラッシュとニトロの光が周りを照らします（中・高画質）
- 画質（低・中・高）でテクスチャ解像度も切り替わります（ゲームを読み込み直すと反映されます）

## 挙動と音

- 6速の自動変速。回転数・ターボの過給・トルクの出方が加速に影響し、HUDにギアと回転計を表示します
- サスペンション（ばね＋ダンパー）で、加減速・旋回・着地に合わせて車体が沈み込みます。縁石や砂地では車体が細かく揺れます
- エンジン音は V6 の倍音構成から合成し、回転数・アクセル開度・ターボに合わせて変化します（過給音、ブローオフバルブ、シフト音つき）
- ライバル車のエンジン音・銃声・爆発は立体音響で鳴り、距離による減衰、ドップラー効果、音速による遅れ、峡谷の反響があります
- 風切り音、ロードノイズ、砂利の音、タイヤのスキール音は、速度や路面に応じて鳴ります

## 調整

ファイル先頭の数値を変えると調整できます。

- `CONFIG`：ゲームバランス・ドリフト・グラフィック
- `PARTS`：パーツの性能と値段
- `DRIVETRAIN`：ギア比・変速する回転数
- `SND`：音量バランス
